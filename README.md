# AudioPlayer

Аудиоплеер на C# 14, .NET 10 и WPF с русским интерфейсом и архитектурным разделением UI, логики и инфраструктуры.

## Возможности

- Воспроизведение локальных MP3 и WAV.
- Play, Pause, Stop, предыдущий и следующий трек.
- Перемотка, таймкоды, громкость и отключение звука.
- Автопереход, Repeat Off/One/All и Shuffle.
- Добавление файлов, рекурсивное сканирование и отслеживание открытой папки.
- Drag & Drop, удаление, очистка, двойной клик и сортировка DataGrid.
- Сохранение и загрузка плейлистов JSON и M3U.
- Чтение Title, Artist, Album, Year, Genre, длительности и обложки через TagLib#.
- Тёмная и светлая темы через ResourceDictionary.
- Выбор темы в меню «Вид» и отдельная настройка автоматически загружаемой музыкальной папки в меню «Файл».
- Автоматическое сохранение громкости, последнего трека и режимов воспроизведения.
- Обработка недоступных, удалённых и повреждённых файлов.

## Горячие клавиши

- `Ctrl+O` — открыть аудиофайлы.
- `Ctrl+S` — сохранить плейлист.
- `Space` — воспроизведение или пауза.
- `Delete` — удалить выбранный трек.

## Структура решения

- `AudioPlayer.UI` — WPF Views, ViewModels, команды, диалоги и темы.
- `AudioPlayer.Core` — модели и контракты сервисов.
- `AudioPlayer.Infrastructure` — аудиодвижок, файлы, теги, плейлисты и JSON-настройки.

## Зависимости

- .NET SDK 10.0 и Windows Desktop Runtime.
- TagLibSharp 2.3.0 для чтения метаданных.
- Встроенный WPF MediaPlayer для воспроизведения через мультимедийный стек Windows.

## Сборка и запуск

```powershell
dotnet restore AudioPlayer.sln
dotnet build AudioPlayer.sln
dotnet run --project AudioPlayer.UI
```

Настройки пользователя сохраняются в `%LOCALAPPDATA%\AudioPlayer\settings.json`.

## Форматы плейлистов

- JSON хранит версию формата и абсолютные пути к трекам.
- M3U сохраняется в UTF-8 и поддерживает абсолютные и относительные пути при загрузке.
